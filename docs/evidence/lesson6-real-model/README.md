# 第六课真实模型验证材料

模型接口采用用户提供的 OpenAI-compatible 网关。请求与网关响应中的模型标识均为 `glm-5.3-flash`。这些记录证明实际发起了外部 HTTP 调用，不用于独立证明网关背后的厂商部署。

## 文件对应关系

- `execution-knowledge.json`：关键词“磁铁”，命中 1 个 A 班切片，绑定内置解题引导与上传的证据摘要 1.0.1。
- `execution-mcp.json`：计算 37 × 23，MCP 返回 851，模型依据结果组织回答。
- `execution-skill.json`：要点提取技能处理完整的三句话，返回三个要点。
- `model-wire-002.json`：MCP 场景首次模型请求、工具定义及模型返回的工具调用。
- `model-wire-003.json`：MCP 工具结果回传模型的请求，以及最终模型响应。
- `model-wire-006.json`：Skill 场景首次请求及模型返回的动作调用。
- `model-wire-007.json`：Skill 执行结果回传模型的请求，以及最终模型响应。
- `model-wire-008.json`：包含已选知识片段和上传技能指令的请求，以及知识问答响应。
- `auth-and-isolation.json`：无凭据 401、Bearer 身份恢复 200、跨班材料 404、学生上传技能 403。
- `direct-runtime-check.json`：应用改为直接连接网关后再次完成 17 × 19 = 323；不依赖采集转发器。
- `screenshots/`：浏览器实际截图，包含应用页面、后端 JSON 响应和后端请求日志。

## 采集方式

验收期间使用本机转发采集程序记录应用实际发出的模型请求和外部网关实际返回的响应。记录排除了 Authorization 和 Cookie 等凭据头。截图中的日志视图将已采集的消息正文按换行展开，工具定义及返回值来自同一份 JSON。报告中部分图片裁去空白或聚焦关键字段，原始截图和完整 JSON 一并保留。

最终运行配置已恢复为应用直接访问远程网关。密钥只在本机 `.env` 中，未提交。知识助手本次采用项目已有的 `keyword` 模式，未调用模拟嵌入接口。本目录中的问答与工具调用响应均由远程模型接口实际返回。

## 验证范围

本组证据对应阶段性验收截图中的五项功能及五个验证问题。它不声称覆盖课程网站任务清单中的全部扩展要求，例如同伴交叉验证或任意 MCP 服务的登记管理。
